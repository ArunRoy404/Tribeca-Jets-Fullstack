description: Review one CRM module with the owner (the module-by-module review)
---

1. `git pull` on branch `roy`. Read `HANDOFF.md`, `AGENTS.md` and `docs/REVIEW_PLAYBOOK.md`.
2. Find the module in the Review order table of `docs/MODULES.md` and its section in `docs/MODULE_FEATURE_STATUS.md`.
3. Follow `docs/REVIEW_PLAYBOOK.md` section 4, step by step. Stop after step 2 and wait for the owner's decisions.
4. After the fix, give the owner numbered test steps. Mark it done only when they say it works; commit only when they ask.
