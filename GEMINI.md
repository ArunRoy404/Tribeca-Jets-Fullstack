# Tribeca Jets Command Center — entry point for Gemini / Antigravity

This file carries no rules of its own. Before doing anything, read in order:

1. `HANDOFF.md` — where the project is, what is next, the session log.
2. `AGENTS.md` — the whole rulebook (applies to every AI tool, not only Codex).
3. `docs/REVIEW_PLAYBOOK.md` — how a module is reviewed and how the owner works.
4. `docs/MODULES.md` (Review order table) and `docs/MODULE_FEATURE_STATUS.md`.

Never commit or push unless the owner says so in that message. Stay inside
the module under review. Update `HANDOFF.md` before the session ends.
